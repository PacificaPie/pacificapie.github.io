Rhythm Coach 节奏教练 working title暂定名

Practice drums at home — tap it out, and get coached the moment you stop. 在家练鼓，敲完就有教练点评。

What it actually is 在干嘛

instant layer即时层

A local, deterministic engine in the browser — lookahead metronome, ±ms feedback on every hit, session stats. Milliseconds are code's job, so the timing never lies. 浏览器本地的确定性引擎——lookahead 节拍器、每一击 ±ms 反馈、会话统计。毫秒的事交给代码，判定不含糊。

coaching layer教学层

When you stop, Claude turns the structured data into a three-part report — diagnosis · prescription · why — and it remembers you: an anonymous profile tracks growth, so each report can answer last time's prescription. 敲完，Claude 把结构化数据写成「诊断 · 处方 · 解释」三段报告；而且记得你——匿名档案追踪成长，报告会回应上次的处方。

on-beat准 close偏 miss丢
Taiko-game feel: notes flow to the judgment ring and you tap — space, touch, or an e-drum. All drum sounds are synthesized (stick click + kick + snare), zero samples, zero licensing. Only public-domain and traditional scores. 太鼓音游风：音符流到判定圈就敲——空格 / 触屏 / 电子鼓都行。鼓声全部合成（鼓棒 click + 底鼓 + 军鼓），零采样、零版权；乐谱只收公有领域与传统素材。

Status:  runs locally, not deployed yet — and the name is still in the parking lot. 状态： 本地能跑，还没部署——名字也还在停车场里。
