A skill is a small, versioned playbook an AI agent can load: trigger conditions, an execution order, and hard stops — with the knowledge it needs living in one authoritative document it points to. Whenever a workflow of mine starts repeating, I compile it into one. These are the eight I can show. skill 是 agent 可加载的小型剧本：触发条件、执行序、硬中止， 它依赖的知识正文放在它指向的唯一权威文档里。 一个工作流开始重复出现，我就把它固化成一个 skill。这里是可以公开的 8 个。

Thin shell薄皮原则

A skill carries triggers, order, and stops — never a second copy of the knowledge. One source of truth; everything else is a pointer. skill 只带触发、顺序与中止，不复制知识正文——同一知识只在一处有正文，其余都是指针。

Write-back经验回写

Every real use writes its lessons back into the skill's own knowledge base. The tool gets sharper the more it runs. 每次真实使用都把教训写回 skill 自己的判例与知识库，工具越用越准。

Knowing when not to orchestrate知道何时不编排

Independent playbooks get no orchestration layer. Structure is added when a trigger signal appears — not before. 互不依赖的剧本不上编排层；结构等触发信号出现才加，绝不提前。

Compositions — when skills become systems 组合——当 skills 组成系统

Systems assembled from the components above, plus runtime parts — servers, schedulers, feeds. Components reappearing here is the point: composition means reuse. Three compositions, three shapes — this is agent development. 由上面的组件装配出的系统，外加运行时件——server、定时器、信源。 组件在这里再次出现正是重点：组合的含义就是复用。三个组合，三种形态——这就是 agent 开发。

TripAlarm product loop产品闭环
skill front door → resident server → year-round price watch → push → /lock · /pause · /delete

A conversational skill in front, a resident server behind: the skill files the alarm, the server watches prices year-round, and hits push back through the user's own channel — with commands that steer the loop. 前端是对话式 skill，身后是常驻 server：skill 立闹钟，server 全年盯价， 到价推送回用户自己的通道，/lock /pause 指令收束循环。

Orchestration is the capability; restraint is the judgment. With three compositions running, the third principle above — knowing when not to orchestrate — is a choice, not a limitation. 编排是能力，克制是判断。三个组合在跑，上面的第三条原则——知道何时不编排——才是选择，而不是局限。
